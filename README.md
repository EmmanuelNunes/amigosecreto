## 🌟 Principais Recursos

1. 👤 **Adição Individual e Rápida:** Digite o nome e aperte a tecla `Enter` para adicionar instantaneamente.
2. 📝 **Adição Inteligente em Lote:** Cole uma lista inteira de nomes separados por vírgula (ex: `Lucas, Maria, Carlos, Fernanda`) e todos serão incluídos de uma vez só!
3. 🛡️ **Prevenção de Duplicatas e Validação:** Impede nomes vazios, espaços excessivos ou repetição acidental de amigos já cadastrados.
4. 🏷️ **Visualização em Chips Interativos:** Cada amigo adicionado aparece em uma etiqueta visual organizada.
5. 🎲 **Algoritmo de Sorteio Justo:** Sorteia de forma perfeitamente aleatória qualquer membro da lista.
6. 🎊 **Explosão de Confetes:** Ao revelar o sorteado, o app dispara uma animação de confetes em tela cheia usando a biblioteca Canvas Confetti.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Semântica limpa e acessível.
* **CSS3:** Design responsivo, estilização flexível e modo escuro acolhedor.
* **JavaScript (ES6+):** Manipulação da DOM em tempo real e regras de validação sem dependência de frameworks pesados.
* **Canvas Confetti:** Efeitos de partículas visuais de alto impacto.

## 🚀 Como Executar

Não requer instalação de Node.js nem servidores externos:

```bash
# 1. Clone o repositório
git clone https://github.com/EmmanuelNunes/amigosecreto.git
cd amigosecreto

# 2. Abra o arquivo no navegador
# No Windows:
start index.html
# No Linux:
xdg-open index.html
# No macOS:
open index.html
```

---

## 💡 Passo a Passo de Uso

1. **Adicionar Nomes:** Digite o nome no campo ou cole vários nomes separados por vírgula e clique em **"Adicionar"** (ou aperte `Enter`).
2. **Sortear:** Com 2 ou mais pessoas cadastradas, clique no botão **"Sortear Amigo"**.
3. **Comemorar:** Veja o nome sorteado na tela com a chuva de confetes! 🎉
